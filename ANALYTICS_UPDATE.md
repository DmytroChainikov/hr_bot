# Оновлена Аналітика Вакансій

## Огляд

Аналітика вакансій тепер показує **два звіти в одному повідомленні**:
1. **Звіт за день** - що відбулось сьогодні/вчора з кандидатами
2. **Звіт за весь час** - загальна статистика по всім кандидатам вакансії

## Принцип роботи

### 1. Завантаження даних

```
1. Отримати активні вакансії (get_job_openings з filter_status=1)
2. Для кожної вакансії отримати етапи (get_job_stages)
3. Для вибраної вакансії завантажити всіх кандидатів
4. Проаналізувати created_at та updated_at для кожного кандидата
```

### 2. Розподіл кандидатів

#### За день (report_date):
- **Створені** - кандидати з `created_at == report_date`
- **Оновлені** - кандидати з `updated_at == report_date` (крім щойно створених)

#### За весь час:
- Всі кандидати на вакансії з розподілом по етапах

### 3. Структура даних

```python
{
    'vacancy_id': int,
    'vacancy_name': str,
    'vacancy_info': dict,
    'report_date': date,
    
    # За весь час
    'all_time': {
        'total_candidates': int,
        'stages': {
            'stage_name': {
                'count': int,
                'stage_id': int,
                'candidates': [...]
            }
        }
    },
    
    # За день
    'daily': {
        'created_count': int,
        'updated_count': int,
        'created_stages': {
            'stage_name': {
                'count': int,
                'candidates': [...]
            }
        },
        'updated_stages': {
            'stage_name': {
                'count': int,
                'candidates': [...]
            }
        }
    }
}
```

## Переваги нового підходу

### ✅ Ефективність
- Дані завантажуються один раз для обох звітів
- Використовується кешування вакансій
- Мінімум API запитів

### ✅ Зручність
- Вся інформація в одному повідомленні
- Можна швидко переключитись між "сьогодні" та "вчора"
- Візуальні прогрес-бари для швидкого сприйняття

### ✅ Точність
- Чітке розділення created_at vs updated_at
- Кандидати не рахуються двічі (створений сьогодні ≠ оновлений)
- Фільтрація по vacancy_id для точності

## Кешування

### Вакансії
- Кешуються на весь день
- Оновлюються автоматично о 00:00
- Можна примусово оновити кнопкою "🔄 Оновити список"

### Кандидати
- Не кешуються в vacancy_analytics (завжди актуальні дані)
- Кешуються в daily_report для денних звітів

## Кнопки управління

| Кнопка | Дія |
|--------|-----|
| 📅 Сьогодні | Показати звіт за сьогодні |
| 📅 Вчора | Показати звіт за вчора |
| ⬅️ Назад до списку | Повернутись до списку вакансій |
| 🔄 Оновити список | Очистити кеш та оновити список вакансій |

## Технічні деталі

### Методи AnalyticsService

#### `get_vacancy_statistics(vacancy_id, report_date=None)`
- **vacancy_id** - ID вакансії
- **report_date** - дата для денного звіту (за замовчуванням сьогодні)
- **Повертає** - словник з повною статистикою

### Обробка дат

```python
# Парсинг ISO 8601
created_date = datetime.fromisoformat(created_at.replace('Z', '+00:00'))

# Порівняння
if created_date.date() == report_date:
    # Створений в цей день
```

### Фільтрація кандидатів

```python
# Створені сьогодні
if created_at and created_date.date() == report_date:
    created_today.append(candidate)
    continue  # Не рахуємо як "оновлений"

# Оновлені сьогодні (крім щойно створених)
if updated_at and updated_date.date() == report_date:
    updated_today.append(candidate)
```
